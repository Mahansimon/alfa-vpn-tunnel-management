# معماری

- Frontend: React + TypeScript + Vite + Tailwind + RTL + i18n
- Backend: FastAPI + SQLAlchemy + Alembic + PostgreSQL + Redis + WebSocket
- Agent: Python استاندارد، سبک، بدون اجرای shell دلخواه
- Tunnel Adapters: معماری Plugin با Registry و Interface استاندارد
- Security: TLS, token auth, request signing, rate limit, RBAC, CSRF, audit logs

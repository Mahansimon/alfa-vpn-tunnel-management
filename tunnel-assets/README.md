# Bundled tunnel assets

Supplied by the project owner:
- BrokenNode.tar.gz
- backhaul.sh
- backhaul_premium

The Agent installer downloads this bundle from the panel and installs the architecture-appropriate BrokenNode core and Premium Backhaul binary into `/opt/alfa/tunnel-binaries`.

Repository adapters:
- https://github.com/AminMGMT/BackPack
- https://github.com/LivingG0D/paqet
- https://github.com/Musixal/rathole-tunnel
- https://github.com/ppouria/ping-tunnel
